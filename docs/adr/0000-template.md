# ADR NNNN: Title in a few words

- **Status:** Proposed | Accepted | Superseded by ADR NNNN
- **Date:** YYYY-MM-DD

## Context

What problem or question forced a decision? What constraints apply (requirements, platform
behavior, earlier decisions)? State facts, and link every claim about an external system to its
documentation.

## Decision

What we do, stated so it can be checked in code review. If the decision has rules, number them.

## Alternatives considered

Each serious alternative, and why it lost. "Do nothing" counts when it was an option.

## Consequences

What becomes easier, what becomes harder, what we must now test or watch, and what would make us
revisit this decision.

## References

Links to documentation, code, issues and earlier ADRs.
